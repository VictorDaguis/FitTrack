Uso de Inteligência Artificial — FitTrack
Ferramentas utilizadas
Ferramenta	Integrantes	Uso
ChatGPT	Anderson Silva, Gabriel Magro e Victor Hugo Daguis	Brainstorm do conceito da fachada, definição dos CRUDs, planejamento do aplicativo e organização da Entrega 1.


Prompts e aprendizados
1. Escolha da fachada
Prompt utilizado:
Quais ideias de aplicativos de fachada podem funcionar para um aplicativo de apoio camuflado e ser implementadas com React Native?

Uso: levantamento de possibilidades de fachada para o projeto.
Aprendizado/revisão: o grupo comparou as ideias e decidiu utilizar uma aplicação de academia, por ser uma fachada comum e permitir uma navegação mobile clara.
2. Divisão dos CRUDs
Prompt utilizado:
Para um grupo de 3 alunos, como dividir os CRUDs e as entidades de um aplicativo de academia que esconde uma área de apoio?

Uso: planejamento inicial das responsabilidades individuais.
Resultado revisado pelo grupo:
- Anderson Silva - Treinos
- Gabriel Magro - Exercícios
- Victor Hugo Daguis - Contatos de confiança
3. Modelagem do DER
Prompt utilizado:
Monte uma modelagem inicial com tipos INT, VARCHAR, DATE, DATETIME e DECIMAL, indicando PK e FK para os CRUDs de Treinos, Exercícios e Contatos.

Uso: apoio à definição dos atributos e relacionamentos do DER.
Aprendizado/revisão: os integrantes revisaram os campos, os tipos de dados e os relacionamentos antes de incorporá-los ao documento.
4. Navegação mobile
Prompt utilizado:
Defina uma navegação React Native usando Stack, Tab e Drawer para uma fachada de academia e uma área protegida, incluindo quick exit.

Uso: planejamento do fluxo de navegação da fachada e da área de apoio.
Aprendizado/revisão: o grupo decidiu usar Stack para a troca entre fachada e área protegida, Tab para os módulos principais da área real e Drawer para funções secundárias, com Quick Exit retornando à fachada.
Regra de revisão
As sugestões produzidas com apoio de IA não serão utilizadas de forma automática. O grupo deve revisar, adaptar e compreender o material antes de incorporá-lo ao projeto. Código, texto ou modelagem gerados posteriormente deverão ser registrados neste arquivo conforme forem utilizados.
