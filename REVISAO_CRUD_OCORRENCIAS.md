# Revisão do CRUD de Ocorrências

## Responsável

Luhan Marques

## Funcionalidades analisadas

O CRUD de Ocorrências do FitTrack foi revisado considerando as operações de criação, consulta, edição e exclusão de registros.

### 1. Criação

- Cadastro de novas ocorrências.
- Preenchimento de data, tipo, descrição e gravidade.
- Validação dos campos obrigatórios.

### 2. Consulta

- Exibição das ocorrências cadastradas.
- Apresentação dos dados de cada registro.
- Exibição de mensagem quando não existem ocorrências cadastradas.

### 3. Edição

- Recuperação dos dados da ocorrência selecionada.
- Preenchimento do formulário para edição.
- Atualização dos dados do registro.

### 4. Exclusão

- Solicitação de confirmação antes da exclusão.
- Remoção do registro selecionado.

## Considerações finais

A revisão identificou a implementação das quatro operações do CRUD de Ocorrências, incluindo validação de campos e confirmação de exclusão.

Esta documentação registra a análise da funcionalidade como parte da contribuição individual para o projeto FitTrack.
