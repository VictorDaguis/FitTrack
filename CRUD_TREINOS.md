# Documentação da Contribuição Individual – CRUD de Exercícios

**Integrante:** Gabriel  
**Funcionalidade:** CRUD de Exercícios  
**Branch:** `feat/crud-exercicios`  
**Tecnologias utilizadas:** Node.js, Express, SQLite e GitHub

## 1. Objetivo

O objetivo da minha contribuição no projeto foi participar do desenvolvimento e da validação do CRUD de Exercícios, funcionalidade responsável pelo gerenciamento dos exercícios cadastrados no aplicativo.

O CRUD permite realizar operações básicas de gerenciamento de dados, possibilitando criar, consultar, atualizar e excluir exercícios.

## 2. Funcionalidades desenvolvidas

Foram consideradas as quatro operações principais do CRUD:

- **Create (Criar):** cadastro de novos exercícios no banco de dados.
- **Read (Consultar):** consulta e visualização dos exercícios cadastrados.
- **Update (Atualizar):** edição das informações dos exercícios existentes.
- **Delete (Excluir):** remoção de exercícios cadastrados.

## 3. Tecnologias utilizadas

- **Node.js:** utilizado para executar o ambiente de desenvolvimento do servidor.
- **Express:** utilizado para estruturar a API e disponibilizar as rotas de comunicação.
- **SQLite:** banco de dados utilizado para armazenar os registros.
- **Git e GitHub:** utilizados para versionamento e registro das contribuições individuais.

## 4. Integração com o aplicativo

O aplicativo foi integrado à API desenvolvida em Node.js com Express e ao banco de dados SQLite. A integração permite que as operações relacionadas aos exercícios sejam realizadas e que os dados sejam armazenados e recuperados do banco de dados.

## 5. Testes e validação

Durante a validação do aplicativo, foram realizados testes das operações do CRUD, verificando o funcionamento das seguintes ações:

- Criação de registros;
- Consulta de registros;
- Edição de registros;
- Exclusão de registros.

As operações foram testadas e validadas, confirmando o funcionamento do CRUD integrado à API e ao banco de dados.

## 6. Contribuição individual no GitHub

Para registrar minha participação individual no projeto, foi definida a criação da branch:

`feat/crud-exercicios`

O código-base já estava presente na branch `main`, sendo necessário organizar a contribuição individual por meio de uma branch específica, realizar o commit e abrir um Pull Request para revisão e integração.

O processo de versionamento foi planejado seguindo as etapas:

1. Atualização da branch `main`;
2. Criação da branch `feat/crud-exercicios`;
3. Registro das alterações por meio de commit;
4. Envio da branch para o GitHub;
5. Abertura de Pull Request direcionado à `main`.

## 7. Conclusão

A implementação e validação do CRUD de Exercícios contribuíram para o funcionamento do aplicativo, permitindo o gerenciamento dos dados de exercícios por meio das operações de criação, consulta, edição e exclusão.

A integração com Node.js, Express e SQLite possibilitou a comunicação entre o aplicativo e o banco de dados. O registro da contribuição individual no GitHub também permite organizar o desenvolvimento em equipe, identificar as responsabilidades de cada integrante e manter o histórico de alterações do projeto.
